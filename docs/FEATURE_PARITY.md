# Matriz de escopo e paridade funcional — FauvoVet

> Referência de **escopo funcional** (não de implementação/visual): páginas públicas do SimplesVet consultadas em
> 14/10/2026 (ver CLAUDE.md §2). Nenhuma equivalência é declarada sem implementação **e** teste.
>
> Implementação atual: PHP/Laravel + MySQL (ADR-010). Evidências apontam para `tests/` e `e2e/`.
>
> Estados: `não iniciado` · `em andamento` · `parcial` · `concluído` (DoD §12.4) · Prioridade: P0 (fundação) → P3.
